# Архив игры «Дурак»

Игра временно исключена из релизной версии по решению пользователя; это архив для последующей доработки и повторной интеграции.

Состав:
- `durak.py`, `durak_store.py` — движок и хранение/онлайн-столы; содержат локальный фикс лимита атаки при переводе.
- `test_durak_engine.py`, `test_durak_store.py` — тесты игры.
- `durak-audit-2026-11-02.md` — аудит и статус сделанного локального исправления.
- `integration.patch` — полный diff интеграции относительно базового коммита `111fedd`.

Пока архив находится вне `app/` и `tests/`: сервер не импортирует эти модули, API игры, плитка и таблица игры удаляются из активного релиза. Для возврата игру нужно сначала доработать по аудиту, а затем применить/пересобрать patch и вернуть тесты в `tests/`.
