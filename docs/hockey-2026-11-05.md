## 2. Хоккейные рынки

Два вида исхода, как договаривались:

* **«Основное время»** — три периода, ничья возможна. Кэфы 1X2 берутся у книги как есть,
  маржу не добавляем (это те же кэфы, что видит игрок в линии).
* **«Победа в матче»** — с овертаймом и буллитами, П1/П2 без ничьей. Считается от
  вероятностей основного времени: `p1 + pX/2`, кэф — с маржой.
* **Тоталы** 3.5 / 4.5 / 5.5 / 6.5 — по голам **основного времени** (гол в овертайме
  тотал не двигает).

Фор, точного счёта и «обе забьют» в хоккее нет — роспись базовая, по договорённости.

Коды сторон в БД: `h:reg:1`, `h:reg:x`, `h:final:2`, `h:total:over:5.5` — префикс `h:`
отличает хоккей от футбольных `f:…` и CS2-шных `a`/`b`.

## 3. Расчёт: два счёта вместо одного

У хоккея важны **два** счёта, и это главное отличие от футбола:

```
matches.reg_a / reg_b    — счёт основного времени (2:2)
matches.score_a / score_b — итоговый счёт (3:2 после овертайма)
```

`settle_hockey(match_id, reg_a, reg_b, final_a, final_b)` считает: `reg` — по первому счёту,
`final` — по второму, тоталы — по первому. Ничья в итоговом счёте — ошибка ввода: хоккей
не заканчивается вничью.

**Кто считает:**

| Лига | Как | Почему |
|---|---|---|
| НХЛ | автоматически из фида результатов | в фиде есть `Tr1OR/Tr2OR` (основное время) и `Tr1/Tr2` (итог) |
| КХЛ | вручную админом: `/hockey ID 2:2 3:2` | КХЛ нет ни в фиде livescore, ни в ESPN (400), ни на khl.ru (403) — счёт брать негде |

Матчи, по которым счёта нет, уходят в `awaiting` и ждут админа; в чат уходит подсказка
с готовой командой. `/results` показывает очередь: у хоккея вместо кнопок «победила
первая/вторая» — тот же `/hockey ID 2:2 3:2`.

Найдены и исправлены две ловушки:

1. **Время в хоккейном фиде нулевое.** Soccer отдаёт точный тайм-штамп, хоккей — только
   дату (00:00), а сопоставление матчей требовало разницы меньше 3 часов. С такой проверкой
   НХЛ не нашёлся бы никогда; теперь, если в фиде только дата, сверяем по дню.
2. **Ноги экспресса.** «Победа команды» в экспрессе не имеет ничьей, поэтому считается по
   итоговому счёту: команда, выигравшая в овертайме, не должна «проигрывать» ногу.

## 4. Что видит игрок

Вкладка **«Хоккей»**: карточка показывает «Основное время» (П1 / X / П2), «Победа в матче
(с ОТ и буллитами)» и под кнопкой — тоталы. Турнир подписывается «КХЛ · Регулярный сезон»
(до правки хоккейная подпись теряла лигу и превращалась в «Регулярный сезон»).
Ставка, история и уведомления используют человеческие подписи: «X (основное время)»,
«ТБ 5.5 (основное время)», «П1 (с ОТ)».

## 5. Как проверить руками

```
/health                                  # line.hockey = 30, sync.stats.hockey = 30
/results                                 # очередь: у хоккея — подсказка /hockey ID 2:2 3:2

/hockey 250 4:1                          # только основное время (значит, и итог 4:1)
```
