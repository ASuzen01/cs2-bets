## 2. Хоккейные рынки

Два вида исхода, как договаривались:

* **«Основное время»** — три периода, ничья возможна. Кэфы 1X2 берутся у книги как есть,
  маржу не добавляем (это те же кэфы, что видит игрок в линии).
* **«Победа в матче»** — с овертаймом и буллитами, П1/П2 без ничьей. Считается от
  вероятностей основного времени: `p1 + pX/2`, кэф — с маржой.
* **Тоталы** 3.5 / 4.5 / 5.5 / 6.5 — по голам **основного времени** (гол в овертайме
  тотал не двигает).

Фор, точного счёта и «обе забьют» в хоккее нет — роспись базовая, по договорённости.

Коды сторон в БД: `h:reg:1`, `h:reg:x`, `h:final:2`, `h:total:over:5.5` — префикс `h:`
отличает хоккей от футбольных `f:…` и CS2-шных `a`/`b`.

## 3. Расчёт: два счёта вместо одного

У хоккея важны **два** счёта, и это главное отличие от футбола:

```
matches.reg_a / reg_b    — счёт основного времени (2:2)
matches.score_a / score_b — итоговый счёт (3:2 после овертайма)
```

`settle_hockey(match_id, reg_a, reg_b, final_a, final_b)` считает: `reg` — по первому счёту,
`final` — по второму, тоталы — по первому. Ничья в итоговом счёте — ошибка ввода: хоккей
не заканчивается вничью.

**Кто считает:**

| Лига | Как | Почему |
|---|---|---|
| НХЛ | автоматически из фида результатов | в фиде есть `Tr1OR/Tr2OR` (основное время) и `Tr1/Tr2` (итог) |
| КХЛ | автоматически из фида Flashscore, вручную — как запасной путь | livescore, ESPN (400), khl.ru (403) и championat.com (вход через SberID) КХЛ не отдают, а открытый фид Flashscore отдаёт — см. ниже |

Матчи, по которым счёта нет, уходят в `awaiting` и ждут админа; в чат уходит подсказка
с готовой командой. `/results` показывает очередь: у хоккея вместо кнопок «победила
первая/вторая» — тот же `/hockey ID 2:2 3:2`.

Найдены и исправлены две ловушки:

1. **Время в хоккейном фиде нулевое.** Soccer отдаёт точный тайм-штамп, хоккей — только
   дату (00:00), а сопоставление матчей требовало разницы меньше 3 часов. С такой проверкой
   НХЛ не нашёлся бы никогда; теперь, если в фиде только дата, сверяем по дню.
2. **Ноги экспресса.** «Победа команды» в экспрессе не имеет ничьей, поэтому считается по
   итоговому счёту: команда, выигравшая в овертайме, не должна «проигрывать» ногу.

## 3.1. КХЛ: результаты нашлись в открытом фиде Flashscore

Источники перебрали такие:

| Источник | Результат |
|---|---|
| livescore (`/date/hockey/…`) | 200, но КХЛ в нём нет (только НХЛ) |
| ESPN `hockey/khl/scoreboard` | 400 — лиги у них нет |
| khl.ru (`/calendar/`) | 403 (закрыт от ботов) |
| championat.com (`/hockey/_superleague.html`) | редирект на вход через SberID |
| sofascore | 403 на API |
| **flashscore** (открытый фид) | **200, есть счёт по периодам** |

Как устроено (`app/services/khl_results.py`):

* фид `https://local-global.flashscore.ninja/2/x/feed/f_4_<день>_3_en_1` с заголовком
  `x-fsign` — блок на матч, поля через `÷`;
* `BA/BB`, `BC/BD`, `BE/BF` — голы по периодам, `AG/AH` — итоговый счёт,
  `AB = 3` — матч закончен, `AC` — стадия (10 — овертайм, 11 — буллиты);
* **основное время = сумма трёх периодов**, итог берём из `AG/AH`. Проверено на трёх
  неделях реальных матчей: у пяти встреча расчёт разошёлся с итогом — это были
  овертаймы и буллиты (`Sochi — Avangard Omsk`: 1:1 в основное, 2:1 в овертайме);
* названия у Flashscore английские и городские («Magnitogorsk» вместо «Metallurg Mg»),
  поэтому сравниваем не строки, а **клубы**: у каждого клуба КХЛ есть набор русских и
  английских алиасов. Незнакомое название → матч не считаем, он ждёт админа;
* порядок команд может быть обратным — тогда счёт разворачивается под наш.

Проверка на вчерашнем игровом дне (реальные данные, не мок): из пяти матчей КХЛ
автоматически рассчитались четыре, пятый (Адмирал — СКА) не попал в окно ±6 часов
из-за тестового времени старта. В проде время приходит из линии, так что окно
соблюдается.

## 4. Подменю «Клубы» и «Сборные»

Футбол и хоккей разделены на два подменю: **Клубы** (лиги, еврокубки, КХЛ, НХЛ) и
**Сборные** (Лига наций, ЧМ, ЧЕ, Кубок Америки, Олимпиада). Категория считается по
названию турнира (`tournament_category` в `app/services/football.py`), а не списком
турниров — новый турнир сборных не придётся дописывать руками. У CS2 подменю нет.

Мелочи, чтобы не было тупиков: при смене подменю сбрасывается фильтр турнира (он был из
другой категории), а если в выбранном подменю матчей нет, а в другом есть — приложение
само переключается.

## 5. Что видит игрок

Вкладка **«Хоккей»**: карточка показывает «Основное время» (П1 / X / П2), «Победа в матче
(с ОТ и буллитами)» и под кнопкой — тоталы. Турнир подписывается «КХЛ · Регулярный сезон»
(до правки хоккейная подпись теряла лигу и превращалась в «Регулярный сезон»).
Ставка, история и уведомления используют человеческие подписи: «X (основное время)»,
«ТБ 5.5 (основное время)», «П1 (с ОТ)».
