## 1. Расчёты и деньги

Проверено на реальных сценариях (файл `tests/test_full_scenarios.py`, 20 тестов) и пробами прямо по API мини-аппа.

| Что проверяли | Результат |
|---|---|
| Карта CS2: 13:11, 12:12, 16:14, 17:15, 19:17 | 13:11 → `a`; 12:12 → победителя нет (овертайм); 16:14 → `a`; 17:15 → ждём; 19:17 → `a` — верно |
| Bo1 / Bo3 / Bo5 | `required_maps` = 1 / 2 / 3; серия 2:0 в Bo3 закрывает 2 карты и возвращает третью (`{settled: 2, refunded: 1, waiting: 0}`) |
| Сыгранная карта без счёта | уходит в `awaiting`, а не в возврат — верно |
| Футбольные рынки: исход, двойной шанс, обе забьют, тотал, точный счёт, проход | считаются по счёту, `exact` вне сетки 0..4 — «other» |
| Экспресс: победа, проигрыш, void-нога | 1.8×2.0 при ставке 100 → 360; с отменённой ногой кэф пересчитывается (→ 150), а не сгорает |
| Повторный расчёт/отмена | `MatchAlreadySettled`, деньги не двигаются; леджер сходится |
| Инвариант денег | после каждой операции: баланс = стартовый + Σ всех записей леджера |
| Ставка больше баланса, ставка 0 и −50, «ничья» в CS2, несуществующий матч/карта, ставка на завершённый и отменённый матч | все отклоняются с понятным текстом |

**Найдено и исправлено:**

| Баг | Что было | Стало |
|---|---|---|
| «Ставок в игре» не считает футбол | `user_active_bets` фильтровал только `market IN ('match','map')` — на главном экране 2 активные ставки вместо 4, а `/api/bets` показывал все | `market IN ('match','football')`; счётчик и список сходятся |
| Ставка на карту из чужого матча принималась | `POST /api/bet {market:"map", map_id:<чужая карта>}` → 200, ставка записывалась с чужим `match_id` и в истории висела не под тем матчем | 400 «Эта карта — из другого матча» |
| Мусор в сумме ронял API в 500 | `amount:"abc"` → `500 {"error":"Внутренняя ошибка: invalid literal for int()…"}` — игрок видел текст исключения | терпимый разбор чисел, 400 «Сумма должна быть положительной» (то же для `/api/express`) |

## 2. Уведомления

Проверены тексты всех событий, которые игрок и админ реально получают: ставка сыграла (с маскотом), не зашла,
возврат, расчёт карты, расчёт футбольного матча, экспресс (победа/проигрыш/возврат), «ждём результат»,
часовая перепроверка, суточная сводка «всё верно», оповещение о сбое.

| Что проверяли | Результат |
|---|---|
| Персональные сообщения по каждой ставке, суммы и баланс в тексте | верно, `round(ставка × кэф)` |
| HTML-экранирование имён команд (`&`, `<`, `>`) | `html.escape` работает — теги из названия команды не ломают сообщение |
| Маскот на выигрыш (`send_photo`), обычный текст на проигрыш/возврат | верно |
| Перепроверка: расхождения — сразу, «всё верно» — не чаще раза в сутки, сбой — сразу | логика в `RecheckLoop` соответствует; на проде `runs: 1, last_problems: false` |
| Уведомление о расчёте карты («Карта 2 · 13:9») | верно |

**Найдено и исправлено:**

| Баг | Что было | Стало |
|---|---|---|
| Футбольная карточка матча с иконкой CS2 | `🎮 <b>Премьер-Лига</b>…` и «📊 Счёт по картам: 1:2» — то есть про карты в футболе | `⚽️` и «📊 Счёт: 1:2» (для CS2 осталось «Счёт по картам») |
| Возврат по несыгранной карте врал про отмену матча | «⚪️ Ставка возвращена… **Матч отменён**, ставка не считается» — хотя серия сыграна, не играли только карту | «Карту не играли, ставка возвращена»; при отмене матча текст прежний |
| Подпись турнира теряла формат серии | `Counter-Strike. IEM Пекин. Групповой этап. Bo3` → «IEM Пекин» (в боте и в приложении) | «IEM Пекин · Bo3» — игрок видит, сколько карт в серии |
| В приложении вместо лиги мог показаться тур | `Премьер-Лига. 12-й тур` → «12-й тур» | «Премьер-Лига»: стадии (тур, сезон, этап, плей-офф) отсекаются |

## 3. Дизайн и вёрстка

Методика: Playwright, 9 экранов × 2 разрешения (390×844 и 360×640), замер `scrollWidth` против ширины экрана,
поиск элементов за границей экрана, проверка минимального кегля и размеров кнопок, консольные ошибки JS.
Скриншоты — в `/home/user/ui-audit/` (`390x844-*`, `360x640-*`, `detail-*`, `final-*`).

| Найдено | Где видно | Исправлено |
|---|---|---|
| **Горизонтальный скролл из-за длинных названий команд**: страница 445 px при экране 360/390, кнопка кэфа вылезала за карточку (`.odd` справа 444 при экране 360) | «Матчи», шторка ставки | `.odd`/`.odd .name` сжимаются, название обрезается многоточием; на телефоне ничего не уезжает |
| Строки карт выпирали на 3.8 px на 360 | «Матчи» (CS2, карты) | `min-width:0` + на узких экранах «Карта 1» → «К1»: названия команд снова влезают целиком |
| **На экране «Экспресс» печатались сырые теги**: «Исходов: `<b>2</b>` · итоговый кэф: `<b>4.04</b>`» | «Экспресс» | собирается как HTML: «Исходов: **2** · итоговый кэф: **4.04**» |
| Названия кэфов центрировались (кнопка наследует `text-align:center`) | «Матчи» | название слева, кэф справа — как в остальных списках |
| Длинное название ноги экспресса обрезалось в одну строку | «Экспресс» | перенос на две строки (`-webkit-line-clamp: 2`) |
| Подписи на колесе фортуны 9 px | «Бонусы» | 10 px |
| В истории операций: «ставка · матч #4» — внутренний id вместо матча, и строчная первая буква | «Я» → История операций | «Ставка · Арсенал — Челси», у карт «ставка · карта 1 · PARIVISION — Natus Vincere»; причина с заглавной |

Что проверили и осталось как есть: отступы карточек (12–13 px), кегли (11.5–15 px в тексте, 19 px в табло),
тап-таргеты (кнопки ≥ 36 px, кроме сегментов-переключателей — это осознанно компактный ряд),
контраст на тёмной теме, скролл вниз без «прыжков», ошибок JS в консоли нет (кроме заблокированного
`navigator.vibrate` — это политика Chrome, в Telegram вибрация работает).
