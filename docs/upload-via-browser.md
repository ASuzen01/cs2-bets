# Загрузка кода на GitHub через браузер (без терминала)

Нужно: скачанный `cs2-bets.zip`. Внутри — папка `telegram-bot` с кодом.

---

## Шаг 1. Распаковать архив

- **Windows:** правый клик по `cs2-bets.zip` → «Извлечь всё» → «Извлечь».
- **macOS:** двойной клик по архиву.

Появится папка **`telegram-bot`**. Зайди в неё — внутри должны быть видны:
`bot.py`, `miniapp.py`, `render.yaml`, `Dockerfile`, папки `app`, `docs`.

## Шаг 2. Создать репозиторий

1. <https://github.com> → войти.
2. Кнопка **+** (справа сверху) → **New repository**.
3. **Repository name**: `cs2-bets`
4. Выбрать **Public** (так Render подключится без лишних разрешений).
5. **Галочки `Add a README file`, `.gitignore`, `license` — не ставить.**
6. **Create repository**.

## Шаг 3. Загрузить файлы

1. На странице нового репозитория нажать ссылку **uploading an existing file**
   (или **Add file → Upload files**).
2. Открыть папку `telegram-bot` **в проводнике/Finder**.
3. Выделить **всё содержимое** внутри неё (Ctrl+A / Cmd+A) и перетащить в окно браузера.

   ⚠️ Важно: перетаскивать **содержимое** папки, а не саму папку `telegram-bot`.
   Если перетащить папку, файлы окажутся внутри `telegram-bot/`, и Render не найдёт
   `render.yaml` в корне.

4. Дождаться, пока список файлов загрузится (58 файлов, пару секунд).
5. Прокрутить вниз → поле сообщения можно оставить пустым → **Commit changes**.

## Шаг 4. Проверить результат

На главной странице репозитория должно быть **в корне**:

```
app/    docs/    bot.py    miniapp.py    render.yaml    Dockerfile    README.md
```

Проверки:

- [ ] Есть файл **`render.yaml`** прямо в корне (не внутри папки).
- [ ] **Нет** файла `.env` (если появился — удалить: он содержит токен бота).
- [ ] Нет папки `telegram-bot` вокруг всего.

**Если всё оказалось внутри папки `telegram-bot`:** удали репозиторий
(Settings → внизу **Delete this repository**), создай заново и повтори шаг 3,
выделяя именно содержимое.

### Мелочь про скрытые файлы

Браузер иногда не захватывает файлы, начинающиеся с точки (`.gitignore`).
Если их не видно в списке загруженного — это не критично для запуска. Чтобы добавить:

1. **Add file → Create new file**
2. В поле имени написать `.gitignore`
3. Вставить:

```
.env
.env.*
!.env.example
data/
*.db
*.db-wal
*.db-shm
__pycache__/
*.pyc
.venv/
venv/
.pytest_cache/
.idea/
.vscode/
.DS_Store
*.log
.cache/
```

4. **Commit changes**.

---

## Шаг 5. Подключить Render

1. <https://render.com> → **Get Started** → войти **через GitHub** (карта не нужна).
2. В дашборде: **New → Blueprint**.
3. В списке репозиториев выбрать **`cs2-bets`** → **Connect**.
   Если репозитория нет в списке: **Configure account** → дать доступ к нему.
4. Render прочитает `render.yaml` и покажет сервис `cs2-bets-bot`, а ниже — три пустых поля:

   | Поле | Что вписать |
   |---|---|
   | `BOT_TOKEN` | токен из @BotFather (вида `9109017457:AAHE…`) |
   | `ADMIN_IDS` | твой telegram id числом |
   | `DATABASE_URL` | строка подключения из Neon целиком |

5. **Apply** → начнётся сборка Docker-образа, 3–5 минут.

## Шаг 6. Проверить, что живёт

| Куда зайти | Что должно быть |
|---|---|
| `https://<имя-сервиса>.onrender.com/health` | `{"ok": true, "mode": "webhook"}` |
| `https://<имя-сервиса>.onrender.com/` | экран приложения с матчами |
| Telegram → бот → `/start` | меню с кнопкой **📱 Открыть приложение** |

Имя сервиса видно в дашборде Render вверху страницы (например `cs2-bets-bot`).

---

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| Render: **No blueprint file found** | `render.yaml` не в корне → проверь шаг 4 |
| Render: сборка падает на `Dockerfile not found` | то же: файлы внутри лишней папки |
| В логах `Exited with status 3` | не заполнены `BOT_TOKEN` / `DATABASE_URL` → Environment → вписать |
| Приложение открылось пустым | проверь, что `MINIAPP_URL` = адрес сервиса (Render ставит сам; если нет — добавь вручную) |
| `409 Conflict` в логах | локально всё ещё запущен бот с тем же токеном — останови его |
| Первый вход грузится ~40 секунд | сервис спал; лечится бесплатным пингом `/health` раз в 10 минут (cron-job.org) |

## Как обновлять код потом (без git)

Правки в браузере: открой файл на GitHub → карандаш ✏️ → изменить → **Commit changes**.
Render перезапустит сервис автоматически через минуту.
