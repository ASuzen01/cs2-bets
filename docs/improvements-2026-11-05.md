## P1. Полировка UX (≈ день)

- **Тост «Максимум за раунд» перекрывает карточки рынков** — показывать его в нижней зоне / короче / с автоскрытием 2 с.
- **Шапка на 320 px** рвётся: «Добр…», «локальны…». Уменьшить кегль на узких экранах, `text-overflow: ellipsis`, убрать дубли (город в подписи и в строке).
- **Колесо: 0 на 8 из 24 сегментов (33 %)** — либо выровнять вероятности, либо честно показать «пусто» как отдельный сектор-проигрыш, чтобы это читалось как правило, а не баг.
- **«Топ» — всего 2 строки.** Сделать топ-10 + периоды (день/неделя/всё время) + подсветку себя, даже если не в топе.
- **История операций без заголовков колонок** — группировка по датам («Сегодня», «Вчера»), заголовки, иконки +/-.
- **Пустые состояния**: «Ставок пока нет» + кнопка «К матчам»; «История пуста» + «Крутить колесо».
- **Деньги должны «ощущаться»**: анимация баланса (+250 🪙 подпрыгивает), сумма выигрыша в тосте, а не только в карточке.
- **Тап-таргеты и a11y**: 44 px минимум, `aria-label` у иконочных кнопок (колокольчик, закрытие), контраст подписей на тёмной теме.
- **Загрузка без мигания**: скелетоны строк линии вместо пустого экрана при `refreshSide`, сохранение скролла при смене вкладок (сейчас прыгает).

## P2. Продукт: чтобы возвращались (2–3 дня на порцию)

1. **Ежедневные задания** (3 штуки: «поставь ординар», «забери бонус», «поставь на хоккей») → 100–300 🪙. Даёт причину заходить каждый день, а не только к матчу.
2. **Серия дней (streak)** — 3/7/14 дней подряд с множителем к ежедневному бонусу. Дешёво в реализации (одна колонка + счётчик), сильно тянет retention.
3. **Шаринг купона картинкой** — «поделиться ставкой» в чат друга/канал. Бесплатный вирусный канал, у бота уже есть маскот и генерация текста.
4. **«Повторить ставку»** из истории и из карточки купона — один тап вместо трёх экранов.
5. **Любимые команды / лиги** — звёздочка у матча, фильтр «Только мои». Игрок CS2 хочет видеть свои 3 команды, а не 60 матчей.
6. **Push о расчёте ставки в аппе** — уведомления в Telegram есть (`notify_bettors`), но игрок в мини-аппе их не видит, пока не откроет «Мои ставки». Добавить бейдж/тост «Ставка рассчитана: +240» при `focus`.
7. **Статистика игрока**: винрейт, ROI, любимая лига, самая крупная ставка — на экране «Я». Дешёвая гордость, её скринят.
8. **Аналитика событий** (`bet_placed`, `bonus_claimed`, `casino_spin`, `express_built`, `tab_open`) — без неё непонятно, где именно отваливаются: на листе суммы, на валидации экспресса или на пополнении.

## P3. Инженерия и надёжность (поэтапно)

- **Postgres и масштабирование.** Сейчас одно соединение на процесс и замок в памяти: на одном инстансе Render работает, на двух — нет. Нужен пул (`psycopg_pool`) + `SELECT ... FOR UPDATE` по строке игрока вместо глобального замка.
- **Rate limit** на `/api/*` (простой token bucket на `user_id`): сейчас 4 параллельных запроса — норма, 400 — уже нет.
- **Серверный `max_bet`** для ординаров/экспрессов: лимит казино (`CASINO_MAX_BET`) есть, у ставок — только `min_bet`.
- **`/health` с реальной проверкой**: сейчас отдаёт коммит; добавить пинг БД, возраст последнего синка линии и `503`, если фид не обновлялся > 15 мин.
- **Алерт в Telegram при 5xx**, `/metrics` (кол-во ставок, ошибок, время синка).
- **Бэкапы: проверять восстановление**, а не только создание. Раз в неделю автотест: поднять копию, выполнить `SELECT count(*)` по ключевым таблицам.
- **CI на GitHub Actions**: `ruff check app tests` + `pytest` на push, деплой только после зелёного. Сейчас проверки ручные.
- **Контрактные тесты API**: схема ответов `/api/state`, `/api/bet`, `/api/casino/play` — чтобы правка на сервере не ломала UI молча.
- **Структурные логи + `request_id`** в каждом запросе, чтобы 500 из ревизии можно было найти в логах Render за минуту.

1. **P0 целиком** — это про «не врать игроку про его деньги» (полдня). Пункт 1 уже в `5ab4145`, деплой — вместе с остальными.
