# Купон ставки картинкой — 2026-11-05

Вариант B: рендер на сервере (Pillow) + отправка `send_photo` через бота в личку игроку.
Игрок жмёт «Поделиться картинкой» → бот присылает PNG 1080×1350 → оттуда пересылается другу.

## Коды ответов `/api/share`

- `200 {"ok": true, "sent": true}` — картинка ушла в чат.
- `404` — ставка не своя или не найдена.
- `503` — приложение поднято без бота (`miniapp.py` локально): «Чат с ботом недоступен».
- `502` — бот не смог написать в личку (заблокирован / нет прав).
