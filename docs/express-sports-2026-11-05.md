# Экспрессы на футбол и хоккей — 2026-11-05

Раньше экспресс собирался только из CS2-серий: у футбола и хоккея в карточке матча
просто не было кнопки «В экспресс», а база принимала только стороны `a`/`b`.

## Что теперь можно положить в экспресс

| Линия | Исход | Код в базе | Как считается |
| --- | --- | --- | --- |
| CS2 | П1 / П2 (кто возьмёт серию) | `a` / `b` | по победителю серии |
| Футбол | П1 / X / П2 | `a` / `x` / `b` | по итоговому счёту, ничья — полноценный исход |
| Хоккей | Основное время П1/X/П2 | `h:reg:1` / `h:reg:x` / `h:reg:2` | по счёту трёх периодов |
| Хоккей | Победа в матче с ОТ и буллитами | `h:final:1` / `h:final:2` | по итоговому счёту |

Один матч — одна нога (как и было): два исхода одного матча в экспресс не берутся.

## Что сделано

| Файл | Что |
| --- | --- |
| `app/services/legs.py` | **новый**. Один код исхода → кэф, подпись и результат. `odds(row, side)` берёт кэф из колонок матча для 1X2 и из росписи (`markets_of`) для рынков; `label()` даёт человеческую подпись («Ничья», «ЦСКА (осн. время)», «Авангард (с ОТ)»); `outcome()` считает ногу по счёту рассчитанного матча. |
| `app/db/database.py` | `place_express` больше не требует `a`/`b`: сторону проверяет `legs.odds`, кэф всегда из базы. `_resolve_expresses` подтягивает строку матча и считает каждую ногу через `legs.outcome` — рынок по счёту, исход матча по победителю. Ногу помечаем всегда, даже если экспресс уже рассчитан по другой ноге (иначе в истории навсегда висело «ждёт»). |
| `app/web/server.py` | `/api/express` пропускает любые коды исходов, ошибку про отсутствующий кэф отдаёт база. Кэфы ног в ответе читаются из `express_items`, а не из запроса клиента. |
| `app/web/payloads.py` | Ноги в истории подписываются через `legs.label`: в списке видно «Ничья · кэф 3.40», «ЦСКА (осн. время) · кэф 2.10», «Авангард (с ОТ)». |

| `app/texts.py` + правила в мини-аппе | Честно написано, что идёт в экспресс из каждой линии. |
| `tests/test_express_sports.py` | **новый**, 17 тестов. |

Ключевые сценарии в `tests/test_express_sports.py`:

- кэфы и подписи ног для футбола и всех рынков хоккея (нет рынка — нет кэфа);
- экспресс «футбол П1 + хоккей X основного времени» через `/api/express`: 200, кэф = произведение, баланс списан;
- ничья в футболе как нога экспресса — разрешена, на CS2 — отказ;
- экспресс с тоталом хоккея — разрешён; неизвестный рынок — отказ;
- два исхода одного матча — отказ;
- расчёт: футбол 2:0 + победа хозяев с ОТ → «зашла», выплата = ставка × итоговый кэф;
- «X основного времени» заходит при 2:2 в основное и 3:2 в овертайме; «П2 с ОТ» при таком же счёте — мимо;
- ничья в футболе 1:1 + П1 основного времени — экспресс зашёл;
- отменённый хоккейный матч → нога void, платим по остальным ногам;
- проигранный экспресс, вторая нога рассчитана позже — нога всё равно помечается;
- история `/api/bets` после расчёта: `result: won`, выплата, подписи ног.

## Оговорки

- Тоталы и форы в экспресс пока не собираются через интерфейс (в листе только 1X2 и рынки хоккея). База такие коды принимает, так что расширить — это одна строка в списке вариантов.
- В live роспись не считается, поэтому в экспресс из live-матча идут только кэфы линии на исход — так же, как было у одиночных ставок.
